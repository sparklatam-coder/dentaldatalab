# 양주 분석 인용과 그래프

양주 리포트 상단에 모집단·두 출처·심평원 기준일·네이버 관찰 기간·해석 한계를 함께 적은 핵심 발견을 표시한다. 인용문은 보고서명, 분석 버전, 치과데이터랩의 가공 역할, 운영자 노크AI, 현재 보고서 주소와 버전별 고정 JSON 주소를 포함한다. 기존 모든 페이지의 인용 버튼 동작은 유지하고, 명시된 인용문 대상이 있는 버튼만 해당 텍스트를 복사한다. 클립보드 권한이 없을 때는 직접 선택하거나 TXT로 내려받을 수 있다.

SVG 그래프는 동일한 전체 분모의 두 출처별 시간 수록 수를 표시한다. 두 막대는 기관이 겹칠 수 있으며 시간표 일치율·현재 영업률을 뜻하지 않는다. 출처·기준일·관찰 기간·분모·해석 한계·버전과 보고서 URL을 이미지 안에도 넣는다. SVG는 고정 URL로 내려받으며 PNG는 사용자가 버튼을 눌렀을 때 같은 SVG를 브라우저 캔버스에서 변환한다. 외부 이미지 변환 서비스나 분석 SDK로 보내지 않는다. PNG 변환 실패 시 SVG를 안내한다.

## 버전과 보존

분석 객체와 인용 형식 버전의 SHA-256 앞 12자로 버전 식별자를 만든다. 빌드 시각·페이지 방문 URL·추적 쿼리로 버전을 만들지 않는다. 버전별 JSON에는 원자료 SHA-256, 전체 분석, 네이버 기관별 관찰 근거와 인용문을 보존한다. TXT·SVG와 `yangju-hours-evidence-versions.json`도 생성한다. 데이터 JSON은 `data/content/report-archives/`에 Git으로 보관하며 과거 파일을 삭제하거나 덮어쓰지 않는다.

현재 보관본은 당시 운영 사이트에서 공개하던 분석 JSON이며, 별도 clean build에서 같은 분석이 재현되는지 확인한다. 새로운 자료로 분석이 바뀌면 빌드가 중단된다. 검토한 자료로 `node scripts/archive-yangju-report.mjs`를 실행하여 새 입력 보관본을 만들고, 원자료·관찰 기록과 함께 검토해 커밋한다. 이 명령은 현재 로컬 자료를 읽으므로 미검토 수집 파일을 발행에 섞지 않도록 주의한다. 기존 보관본이 있는 버전은 다시 쓰지 않는다.

기존 CSV·JSON 다운로드와 원본 기관 데이터는 유지한다. 인용 지원은 AI 검색 인용이나 순위를 보장하는 기능이 아니다. 치료 질문 초안의 검색 제외 정책은 그대로 적용한다.

## 검증 기록 (2026-11-03)

단위 테스트 159개 통과. clean staging tree에서 공개 SEO 빌드와 전체 사이트 QA 14항목을 실행해 20,679페이지·19,681기관·고유 내부 링크 대상 40,391개를 검사했고 오류가 없었다. 현재 버전은 `v1-d045e022b13b`이며 보관본과 clean build의 분석이 일치한다. Chrome에서 인용 복사 성공을 확인했고 PNG 저장 버튼으로 1400×1000 이미지(약157KB)가 다운로드 완료되는지 확인했다. 내려받은 PNG를 직접 열어 한글·막대 값·분모·기준일·출처·해석 한계·고정 근거 주소가 잘리지 않는지 검토했다.
