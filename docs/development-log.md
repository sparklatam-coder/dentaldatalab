# 2026-10-31 · 로컬 개발 v0.2

## 이번 작업의 범위

사용자가 전달한 전체 대화, 통합 인수인계, 개발 계획 및 ZIP의 소스·원자료·검수 기록을 확인하고, 원본 보존 후 작업 공간 루트에 개발 소스를 구성했다. 기획의 최신 강조점인 **공공데이터 리포트 + 조건 검색**을 첫 구현 단위로 선택했다. 기존 SSG가 요구를 충족하므로 프레임워크·DB를 교체하지 않았다.

## 구현

- 전국 데이터 수록 현황 및 경기북부 등록시간 리포트 2편과 리포트 허브.
- 리포트 중심 홈, 데이터 수록률 카드, 조건 검색 바로가기.
- 순수 집계 함수를 화면 생성과 분리. 경기북부의 원자료 시도·시군구코드를 명시하고 고양 3개 구를 합산.
- 모든 비율에 분모·수록 한계를 제공. CSV·JSON에 지표 정의·자료 확인 분모·누락·출처·원본 해시 포함.
- 리포트는 개별 기관명·마케팅 지표를 노출하지 않음. 기존 기관 상세와 사용자 선택 사실 비교는 유지.
- Dataset 구조화 데이터와 실제 다운로드 연결, sitemap에 리포트 추가, llms.txt에 데이터 범위 설명.
- `npm run dev`: 소스 감지, 순차 빌드, 완성 후 활성 결과 전환. 실패 중에도 마지막 정상 화면 유지. 브라우저 새로고침 필요.
- 로컬 서버는 루프백 주소만 허용하고 모든 HTTP 응답에 noindex 헤더 제공.
- 검색 페이지의 비정수 p 파라미터 및 비교함 비운 뒤 남는 설명·내부 ID 상태 수정.
- 루트 README·Mac 실행 파일을 현재 폴더 구조에 맞게 변경. 원본 인수인계 폴더는 수정하지 않음.

## 다음 개발 우선순위

1. 지역 명칭 혼재를 공신력 있는 대응표와 대조하고 원문·표준 표시를 분리하는 정책 수립.
2. 분기 스냅샷 갱신·차이 검출·검수 이력. 누락된 기관을 즉시 폐업으로 간주하지 않음.
3. 가격·인구·접근성 등 추가 원자료 확보 후 리포트 확장. 데이터 없는 숫자나 치료 가이드를 추정해 채우지 않음.
4. 정정 요청의 실제 저장·검토·회신 흐름과 운영 주체 고지 준비.

이번 변경은 로컬 개발 단계다. 공개 호스팅·DNS·결제·외부 메시지 전송은 진행하지 않았다. 기존 운영자·정정 접수·공개 전 검토 항목은 여전히 미완료다.

`/verification/`와 양주 상세 페이지에 채널 상태·근거·관찰정보를 추가했다. 원자료 검색/비교/리포트 수치는 유지했다. 초기 수려한 관찰의 예약번호/대표번호 설명을 보완하고, 온가족 홈페이지 본문의 연락처 및 시간 안내를 보충했다. 기관 자체 주장이나 후보를 현재 운영 전체의 검증으로 승격하지 않는다.

검토에서 발견한 누락(02 사실 스키마 차이), 확인 플래그 없는 verified 승격 가능성, 검색 색인의 본문 라벨 혼동을 수정했다. 원본 clinics SHA-256은 `22ca2821563ec5ba0a78d903e55585ad3a0ecd5da4ed12bb28e667b51b05c5fc`로 유지된다. 공개 배포 및 외부 연락은 수행하지 않았다.

## 2026-11-01 v0.4 · 치료 질문 100개와 콘텐츠 기획실

한국·한국어 Google 검색, 환자·보호자 대상이라는 사용자 확인에 따라 10개 치료 분류별 10개씩 총 100개 키워드·질문·후킹 제목·짧은 답변을 작성했다. 각 항목에는 검색 의도, 제작 우선순위와 이유, 답변 근거를 연결했다. 임플란트, 교정, 충치·레진·인레이, 신경치료, 사랑니·발치, 보철, 잇몸치료, 미백·라미네이트, 소아·예방, 치과공포·응급·치료안전을 다룬다.

Google 공개 자동완성에 20개 시작 검색어를 대한민국·한국어 설정으로 요청해 서로 다른 198개 예상 검색어를 관찰했다. 원응답·요청 URL·수집 시각·SHA-256을 보존했다. 100개 기획 검색어 중 32개가 실제 응답과 정확히 일치하며 68개는 분류의 관찰 신호를 바탕으로 편집한 세부 질문이다. 이 구분은 질문 문장 자체의 검색 빈도와도 다르다. Keyword Planner 검색량은 확보하지 않았고 Trends 요청은 HTTP429에서 중단했다. 월간 검색량과 순위는 모두 null이다. Google 전체 치과 검색량 상위100을 검증한 결과로 표현하지 않는다.

59개 공식 기관·학회·병원의 안내 페이지를 근거로 연결했다. 한국 보험 조건과 비용 정보는 국내 공공기관 안내로 확인했다. 두 묶음 간 항생제·발치 지혈 중복을 제거하고 골다공증약·오래 지속되는 구강 궤양 질문으로 교체했다. 응급 감염 질문에서 눈 주위 붓기·통증과 시력 문제를 독립적인 응급 신호로 수정했다. 모든 항목은 의료진 검토 대기이며 실제 임상 검토를 받은 것으로 표시하지 않는다.

`/questions/`에 분류·검색 의도·검색 근거·제작 우선순위·텍스트 검색과 답변 펼치기, 각 분류의 첫 제작 후보를 구현했다. 질문별 원문 확인일과 관찰한 시작 검색어를 표시한다. TXT 전체 기획안, 근거와 출처 목록을 포함한 JSON, Keyword Planner 조회용 키워드 TXT를 제공한다. 검색순위나 FAQ 구조화 데이터를 붙이지 않았으며 공개 빌드에는 이 초안과 다운로드가 포함되지 않는다. 기존 19,681개 기관 원자료 해시는 유지된다.

검증 결과: `npm run build`, `npm test` 통과(31개 테스트·정적검사14항목). 404 포함 HTML20,674개 생성. 새 화면 및 다운로드 HTTP5경로에서 200·올바른 MIME·noindex·100개 데이터·출처59개를 확인해 `docs/qa-http-v0.4.json`에 기록했다. 키워드·질문 중복0개, 출처별 파생 문장 보수적 합산 최대197어절이었다.

네이티브 Chrome에서 데스크톱 배치, 비용 검색7개, 복합 검색1개, 답변 전체 펼치기, 펼친 상태에서 필터 변경 후 접기 버튼 유지, 출처·확인일, 빈 결과0개와 버튼 비활성, 동일 해시의 첫 후보 재클릭 시 필터 초기화와 답변 복구를 확인했다. 모바일 실기기·에뮬레이션은 이번 변경에서 확인하지 않았다. 실제 검색량 확보와 의료진 검토가 남아 있으며 공개 배포는 수행하지 않았다.

## 2026-11-01 v0.5 · 검색량 원천과 조사 과정 공개

사용자의 요청에 따라 한국 Google 치과치료 검색량을 비교할 수 있는 원천과 접근 경로를 조사했다. Google 공식 원문 17개, 대체 제공사·네이버 공식 원문 26개의 조사 기록을 각각 `google-source-research.json`, `alternative-source-research.json`에 보존했다. 기존 자동완성 설명과 합쳐 페이지에 필요한 공식 문서 33개를 선정하고, 10개 소스의 지표·범위·접근 요건·사용 목적을 `data/content/search-source-guide.json`에 정리했다.

첫 수집은 Google 키워드 플래너의 과거 월평균 검색량을 권장한다. 후보 발굴을 넓힌 뒤 국가·검색망·실제 집계 월을 맞추고, 근접 변형 묶음·동률·범위·누락을 처리해야 한다. 반복 갱신은 Google Ads API, 조건부 중계 대안은 DataForSEO Google Ads다. Ahrefs·Semrush 모델 추정값은 독립 시리즈이며 Google 제공 통계로 재명명하거나 합산하지 않는다. 네이버 SearchAd 최근 30일 PC·모바일 검색수와 DataLab 상대지수도 별도 범위다.

공식 도움말의 플래너 진입 링크를 실제로 따라가 익명 접속의 Google Ads 로그인 화면을 확인했다. 사용자 계정의 이용 가능 여부나 숫자 표시 정밀도는 확인하지 않았다. 공식 Google 위치 ZIP은 일반 공개 다운로드 후 CSV에서 KR/Country/Active 행을 파싱해 South Korea 2410을 확인했고 해시를 `google-geotarget-check.json`에 기록했다. DataForSEO 공개 위치 CSV도 KR=2410을 확인했지만 언어 목록 API는 무인증 401이므로 중단했다. 네이버 공식 공개 Swagger를 따라 최근 30일·<10 표시를 확인했다. 모두 문서·참조 데이터 조사이며 실제 치과 키워드별 검색량 획득과는 다르다.

`/search-sources/`에 비교표·소스별 접근 조건·순위 수집 절차·표시 규칙·실제 조사 과정·공식 원문 펼침을 구현했다. 각 원문에 확인일과 실제 검색어·찾은 경로를 남기고 전체 조사 JSON을 제공한다. 홈의 리포트 다음에 안내 카드를 두고, 질문 상단 안내와 하단 방법 섹션·공통 하단 메뉴에 연결했다. 기존 ‘한국어 설정’을 한국어 사용자만의 검색량으로 읽지 않도록 고쳤고 ‘100개의 검색 의도’를 ‘치료별 질문과 답변 100개’로 수정했다. 공통 HIRA 출처 문구는 기관 등록 자료에 한정했다.
