# 로컬 v0.2 브라우저 검수

검수일: 2026-10-31. 환경: macOS Google Chrome, 로컬 `npm run dev` 서버. 브라우저 연결 도구가 제공되지 않아 CUA의 Chrome 네이티브 접근성 트리·화면·키보드로 검사했다.

## 확인한 동작

- 데스크톱 홈: 리포트 중심 제목·24.5% 수록률·전국 19,681곳·조건 검색·탐색 링크 표시.
- 경기북부 리포트: 전체 1,190곳, 시간 수록 252곳/21.2%, 미확인 938곳. 10개 시군 표, 분모 안내, 코드 매핑, 원본 출처, 다운로드 링크 표시.
- DevTools 390×844 리포트: 제목·요약·버튼 줄바꿈, 통계 카드 세로 배치, 표 내부 스크롤 확인. 표 영역에 포커스 후 오른쪽 키로 수평 이동. 문서 전체 폭이 표 너비로 밀리는 모습 없음.
- DevTools 320×844 홈: 메뉴와 버튼 줄바꿈, 제목·수록률 카드 표시. 육안 검사에서 가로 잘림 없음.
- `/find/?q=양주&p=1.5`: 검색 304곳, 1/16페이지로 정상화, 비정수 p URL에서 제거. 이름/주소 부분 일치라 남양주도 포함된 결과.
- 검색 결과 3곳 선택 후 4번째 선택 차단 안내, 선택 수 3 유지.
- 비교 페이지에서 3기관 표와 출처·기준일 표시 확인.
- 비교 비우기: 비교 수 0, URL ids 제거, 빈 상태 안내로 교체. 이전 3곳 설명이 남지 않음.
- 기관 상세의 신고 홈페이지 ‘자료 미확인’ 출처 창: 파일명·기준일·수집일·이용 조건 표시.

다운로드 파일의 수치·인코딩·경로는 자동 테스트와 HTTP로 검사했다. 브라우저의 다운로드 저장 위치나 OS 클립보드 복사 결과는 검사하지 않았다. 화면 검사는 실제 모바일 기기나 모든 브라우저의 호환성 검사를 대신하지 않는다.
