# 양주 출처별 시간 정보 분석

새 독자분석은 기존 리포트 등록 함수에서 `/reports/yangju-hours-evidence/` 한 페이지와 CSV·JSON 2개를 제공한다. 기존 리포트의 순수 집계 계약과 API를 유지하고, 원본·수집 파일을 변경하지 않는다.

## 모집단과 재현

`buildYangjuAnalysis`는 심평원 시도코드 `310000`, 시군구코드 `312700`, 종별 `41/51`이 모두 일치하는 기관만 포함한다. 주소에 ‘양주’가 있다는 이유로 포함하지 않는다. 동일 기관 ID의 중복은 오류로 처리한다. 읍면동은 원문 표기로 묶고 미표기를 별도 집단으로 둔다.

심평원 시간은 `report-data.mjs`의 `hasValidHours`를 재사용한다. 같은 날 유효한 시작·종료가 있고 종료가 늦을 때만 포함한다. `00:00` 대체값·잘못된 시각·자정 넘김은 추정하지 않는다. 평일 19:00 이상 종료는 기존 경기북부 리포트와 같으며 19:00 종료도 포함한다. 여러 요일에 중복되는 기관이 있어 요일별 행 합계를 전체 기관 수로 해석하지 않는다.

네이버 시간은 `clinic-hours.mjs`의 `latestNaverHours`를 사용한다. 현재 자산의 정정 이력에서 제외되지 않은 Place이며, 본문 읽음·기관 식별 일치·시간 원문·유효 확인시각을 만족하는 최신 관찰만 포함한다. 후보, 다른 기관, 무효화된 관찰은 집계하지 않는다. 실패한 재접근은 이전의 유효 원문 관찰을 삭제하지 않는 기존 정책을 따른다. 원문을 새 주간 시간표나 야간진료 여부로 파싱하지 않는다.

두 출처의 ‘모두 확인/심평원만/네이버만/모두 미확인’은 상호 배타적으로 모집단 전체를 나눈다. 이는 시간표 내용의 일치율, 정확도 또는 현재 영업률이 아니다. JSON에는 네이버 근거의 기관 ID·원문 URL·확인시각을 함께 제공한다. CSV는 읍면동 분포·요일·수록 상태별 집계와 분모·기준일·제한을 제공한다.

출력에서 빌드 시각이나 `inventory.generatedAt`은 사용하지 않는다. 입력 순서를 바꿔도 같은 JSON을 생성한다. 공식 자료 기준일과 네이버 관찰일을 분리해 표시하고, 복합 Dataset에 단일 관찰일을 잘못 지정하지 않는다.

## 2026-09-30 공식 자료 및 현재 보존 관찰 기준 결과

- 모집단 67곳: 치과의원 66곳, 치과병원 1곳.
- 심평원 시간쌍 확인 4곳, 미확인 63곳. 평일 19시 이상 종료 등록 4곳.
- 네이버 시간 원문 확인 66곳. 관찰시각은 2026-10-31 UTC의 22:35–22:55이며 한국 날짜로 2026-11-01이다.
- 모두 확인 4곳, 심평원만 0곳, 네이버만 62곳, 모두 미확인 1곳.
- 따라서 심평원 시간 미확인 63곳 중 62곳은 별도 네이버 원문을 읽을 수 있었다. 분기 파일의 시간 공란을 실제 안내 부재·휴진으로 취급하면 안 된다.

관찰·정정 데이터가 바뀌면 네이버 수치는 재계산된다. 이 문서의 결과를 미래의 실제 운영 상태로 사용하지 않는다. 인구·면적·치료 수요 자료가 없어 공급 적정성이나 지역별 진료 접근성을 주장하지 않는다.

## 통합

`build.mjs`의 기존 호출에 이미 생성된 두 입력만 추가한다.

```js
registerReportPages({ page, put, reports: reportData, domain, clinics, assetInventory });
```

두 입력이 없는 기존 호출은 새 페이지를 등록하지 않으며 기존 3개 리포트 경로·4개 집계 파일 동작을 유지한다. 두 입력이 있고 양주 모집단이 있을 때만 새 분석과 `/reports/`의 직접 내부 링크를 추가한다. 검색용 별도 동네 페이지를 대량 생성하지 않는다.

## 검증

`test/yangju-analysis.test.mjs`는 코드별 모집단, 실제 분기 합계, 출처별 2×2 합계, 읍면동 합계, 요일별 분모, 후보·정정 배제, 관찰 실패 처리, 빌드 시각 독립성, HTML escape, CSV·JSON 근거 및 기존 등록 함수의 하위 호환을 검사한다.
