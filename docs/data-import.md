이용허락: 공공저작물: 출처표시 (제 1유형). 2026-10-31 원자료 페이지에서 직접 확인했다. 화면에 "출처: 건강보험심사평가원"을 표시한다.

## 재실행

1. 위 페이지에서 "다운로드"로 zip을 받는다(로그인 불필요, 2026-10-31 확인). zip은 재배포하지 않는다.
2. `node scripts/import-hira.mjs --zip <zip 경로> --snapshot 2026-09-30 --collected 2026-10-31T10:27:09.045Z`
   - 원본 v0.1 기본 zip 경로는 프로젝트 상위 폴더입니다. 현재 루트 작업 공간에서는 `--zip "치과데이터랩_개발인수인계_20261031_v1/hira_hospital_pharmacy_20260930.zip"`을 명시하세요.
   - Node 내장 모듈만 사용한다. 약 3초 걸린다.
3. 출력: `data/clinics.json`, `data/source-manifest.json`. `observedAt`은 `--collected`를 우선하고 생략 시 ZIP 파일 수정 시각을 사용한다. `importedAt`은 별도의 가공 실행 시각이다. 사이트의 수집일 표시는 Asia/Seoul 기준이다.

새 분기 파일이 나오면 zip과 `--snapshot`만 바꾼다. 파일명 안의 `병원정보서비스`, `02_세부정보`, `03_진료과목정보`, `05_의료장비정보`가 각각 하나만 매칭되지 않으면 스크립트가 실패한다.
검증이 실패하면(필수 컬럼 누락, CSV 행 너비 불일치, 종별 오류, id 중복, 이름·주소 누락, 세부정보 중복, 시각·좌표 범위, 전체 15,000~30,000곳 범위 이탈) 종료코드 1로 끝나며 파일을 쓰지 않는다. 새 분기에는 기존 기관 ID 유지율과 폐업·이전 처리, 테스트의 기준 수치, 변경 이력 문구를 반드시 다시 검토한다.

## 파일과 인코딩

zip 내부 파일명과 CSV는 CP949이다(`TextDecoder('euc-kr')`). 압축은 deflate이며 스크립트가 직접 해제한다.

## sourceIds

- `hira-base`: 모든 기관(병원정보)
- `hira-detail`: 세부정보 파일에 행이 있는 기관
- `hira-specialties`: 진료과목정보 행이 있는 기관
- `hira-equipment`: 의료장비정보 행이 있는 기관

## 정규화 규칙

- 빈 값은 `null`이다. 0으로 바꾸지 않는다. 미등록 장비를 0대로 추정하지 않는다.
- 진료시간은 `900` -> `09:00`, `2000` -> `20:00`처럼 3~4자리 숫자만 변환한다. 시작과 종료가 모두 유효하고 같은 날 종료가 시작보다 늦을 때만 값을 넣는다. `0`, 빈 값, 형식 불일치나 날짜 넘김 불명확 상태는 `{open:null, close:null}`이다. 종료가 시작보다 늦지 않은 값은 `hoursNotes.unclearHours`에 보존하고 `quality.hoursUnclearDays`로 센다.
- `quality.hoursAvailable`: 한 요일이라도 위 기준으로 유효한 시작·종료가 있으면 true이다.
- `quality.specialtyComparison`: 전체·과목 수 대조 가능 여부를 unavailable / match / different로 구분한다. 값 차이를 오류나 의료적 우열로 단정하지 않는다.
- 홈페이지 값 1,718건 중 `http://` 같은 주소 미완성 값 122건은 링크 가능한 주소 수에서 제외한다. 1,596건은 URL 형식 검사를 통과한 수이며 실제 사이트 운영 확인 수가 아니다.
- 전화번호는 단일 번호 패턴일 때만 `tel:` 링크와 구조화 데이터에 넣는다. 쉼표·점·범위가 섞인 원문은 그대로 보여주고 자동 연결하지 않는다.
- `quality.specialtyCountDiscrepancy`: 치과전문의 인원수와 진료과목별 전문의수 합계가 둘 다 확인되고 서로 다를 때 true이다. 값은 보정하지 않는다.
- 가격 필드는 만들지 않는다(이 파일 묶음에 없음).

## 한계

- 분기 스냅샷이다. 포털 목록에 등록된 과거 분기 파일은 제공하지만, 목록 밖 임의의 과거 시점 자료는 제공하지 않는다. 원자료 안내에 따라 다른 월말 집계와 그대로 비교하지 않는다.
- 요양기호는 암호화 값이라 외부 데이터와의 연결은 이름·주소·전화·좌표로 해야 한다.
- 진료시간은 세부정보에 등록된 일부 기관만 있다.
- 종합병원 등 다른 종별의 치과 진료과목 기관(약 406곳)은 제외한다.
- 개인정보는 다루지 않는다. 기관 단위 공공 정보와 의사 인원수만 포함한다.
