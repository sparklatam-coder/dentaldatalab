# 로컬 개발 실행

Node.js 20 이상에서 프로젝트 루트의 `npm run dev`로 시작합니다. 외부 npm 의존성과 API 키는 필요하지 않습니다. 주소는 `http://127.0.0.1:4173/`이며, 포트가 사용 중이면 `PORT=4174 npm run dev`로 변경합니다.

- `src/`, `scripts/`, `data/` 변경 후 300ms 기다렸다가 전체 정적 사이트를 다시 만듭니다. 빌드 중 추가 수정은 다음 빌드 한 번으로 모아 순서대로 처리합니다.
- `.dev-dist/`의 실행별 임시 폴더에 빌드합니다. 완료된 결과만 서버에 반영하므로 빌드 중에도 마지막 정상 화면을 볼 수 있습니다. 실패하면 이전 화면을 유지하며 오류를 터미널에 표시합니다.
- 첫 빌드가 끝나기 전 요청은 503과 준비 안내를 반환합니다. 반영 완료 로그가 나오면 브라우저를 새로고침합니다. 브라우저 자동 새로고침 기능은 없습니다.
- 기존 `dist/`와 데이터 원본은 수정하지 않습니다. Ctrl+C 종료 시 해당 실행의 임시 산출물을 정리합니다. 비정상 강제 종료 후 남은 `.dev-dist/`는 개발 서버를 모두 종료한 뒤 삭제할 수 있습니다.
- 서버 코드 자체(`scripts/server.mjs`, `scripts/dev.mjs`)를 수정한 경우 Ctrl+C 후 다시 실행해야 실행 중인 서버에도 반영됩니다.

`npm run build`는 검수할 `dist/`를 생성하고, `npm run preview`는 그 결과를 보여줍니다. 개발 서버와 미리보기 서버는 `127.0.0.1`, `::1`, `localhost`만 허용하며 모든 응답에 `X-Robots-Tag: noindex, nofollow`를 붙입니다. 개발 서버는 환경에 production 설정이 남아 있어도 검토 빌드만 생성합니다.

`node --test test/local-server.test.mjs`는 서버의 GET/HEAD/404/리다이렉트/405, JavaScript MIME, 압축, 비공개 헤더, 경로 제한과 완성된 빌드 전환을 실제 HTTP 요청으로 검사합니다.
